# 钓竿钓玩具

同事只需要上传视频。Codex自行选段、选款、准备抠像与背景并验收，默认交付 **60fps MP4 视频**。仅在明确要求 GIF 时附加50fps GIF，最终不以动图或分镜图代替视频。用户说先聊、评估或暂不制作时，只讨论；确认关键试片后，完整版保留已确认动作。

## 制作

1. **审片选时刻。** 运行 `inspect`，实际看时间线，复杂动作再细看。优先保留约5～6秒机器人完整或充分可见、动作有意思的原片；避开装配/遥控器特写和无主体空镜。落钩时选无遮挡、姿态较稳、接触关系明确的一帧。短原片可缩短铺垫，不强凑时长。按真实体量与接地判断：小玩具用 `lift`；普通偏大机器人用 `low_lift`，先受力倾斜再低幅离地；更大型、更重的机器人用 `drag`，倾斜拖走并保留支点接地和摩擦感，不能直立平移。
2. **保留原片。** `prepare` 将选段缓存为原生帧率的无损视频，并导出末帧作为拾取帧。钓起之前只叠加竿、吊坠、线；不提前替换机器人、不先修地面、不提前定格等钩。不要用通用运动补帧把原片快速动作变成重影。新动画逐帧计算60fps，原片保留自身有效帧率。
3. **只抠拾取帧。** 主体包括要带走的布/工具，排除地面、原投影及应留下的鞋和人物。复杂蟹腿、钳子、灰色肢体优先用可选的官方SAM2，细看棋盘格与夹缝，不能只按颜色删背景或删掉眼灯。方法见[抠像](references/matting.md)。挂点必须位于本期主体上；主体在入画阶段移动时，运行 `track` 或填写经过检查的挂点关键帧，跟踪不能改变原片像素。
4. **恢复露出的背景。** 查看本期拾取帧后，用内置图像生成工具仅移除主体及投影，保留原场景、鞋及裤腿。相同拾取镜头的已验收背景可复用，其他视频不复用坐标或补片。检查主体移走后无残影、色块、旧投影或鞋尖跳动；需要时配置保护遮罩。图像生成不可用时说明缺少干净背景，保留准备结果，不交付残影版本、不索要API Key。
5. **编排关键动作。** 使用固定竿和四款挂饰，不每次重画。只有一只持竿手，前臂连接画面边缘，竿/手/线一起从画外进入，不能突然显示或淡入。落钩阶段竿尖在挂点上方，线向下垂；绷紧后手、竿尖与主体共同运动。不要额外加摇轮手或让绞盘自行旋转。小玩具默认约1秒连续完整提走，弯竿与短促滞后表现受力；不长时间蓄力、慢慢漂浮或在半空停顿。偏大主体使用 `low_lift`：先由挂点牵动上身，围绕承重脚/脚尖倾斜，脚部短暂滞后，再低吊带走。更大型、更重主体使用 `drag`：上半身向拉力方向倾倒，承重脚保持接地后滑动，不明显抬高，不能保持直立平移。Codex须按本片检查挂点、支点、倾斜方向和离地高度，不让同事填写参数。姿态变化克制，平面抠像不能生成背面或明显三维翻转。
6. **验收交付。** `preview` 是内部检查图；实际查看导出的 MP4，检查原片到离地的接缝、鱼竿入画、挂点、受力先后、倾斜、接地/低吊高度、速度、投影、鞋/人物，以及所有肢体和道具完整出画。末尾留约0.35秒。`complete --qa-notes` 记录实际检查并仅成功一次推进轮换。最终展示视频并给MP4链接，不默认展示GIF或内部检查图。

## 命令与资产

先运行 `doctor`。依赖安装、命令和离线状态说明见[制作步骤](references/workflow.md)，配置和拖走分支见[项目配置](references/project-config.md)。使用本技能 `.venv`，FFmpeg来自PATH或依赖包，不依赖作者电脑或其他技能。

**关注加号 → 点赞红心 → 收藏五角星 → 向右的转发箭头 → 循环。**

`assets/rods/` 保留四款完整资产；实际渲染用 `assets/rig/` 的同一只手/竿与四款挂饰，允许竿身弯曲、吊坠独立摆动。保持大号比例及符号可读，避免遮住眼睛/挂点，不镜像转发箭头。

**四款符号必须完整展示。** 加号、红心、五角星和转发箭头是核心画面元素，不是可裁切的装饰。送竿入场完成后，从落钩到开始钓走（`enter_end` 至 `pickup`），整个符号必须清楚、连续地留在画面内，包含摆动时的最外轮廓，不能只露半个或贴边裁掉。自然入场和最终出画可以经过边缘。根据本期挂点调整鱼竿位置、角度及挂饰朝向，保留安全余量和大号、易辨认的尺寸；不能靠缩成小图标解决裁切。

验收须单独检查导出MP4中这一展示时段的符号完整性，不能只检查末尾是否出画；裁切、被手/主体遮住或过小难辨认时，调整构图后重新导出。同片修订保留原款，不额外推进轮换。

状态在 `$CODEX_HOME/fishing-gif/rotation.sqlite3`，默认 `~/.codex/fishing-gif/`。同一内容SHA256重做保留原款，改名不换款；失败、预览和修改不额外推进。各同事独立轮换，状态不随安装包分发。测试指定独立 `--state-dir`。显式选 `--variant` 不推进自动轮换。

视频选段、真实体量、遮挡、抠像和背景由Codex判断；脚本负责可重复合成和格式检查。相机剧烈运动、遮挡或缺少视角时先换合适片段，不声称脚本能恢复不存在的视角。仅在用户明确要求时更新外部仓库或发布内容。
